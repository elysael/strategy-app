# 🎈 Strategy Labeling App

This app presents participant explicit learning timecourses. Here, individuals can label strategy timepoints (ie., start of aiming and strategy stabilization). Individuals can also label timecourses as: 1) erratic/exploratory, 2) stepwise, or 3) incremental/gradual.

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
